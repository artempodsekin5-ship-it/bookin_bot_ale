# 📸 Telegram Бот для сбора заявок на съёмку (aiogram 3 + FSM)

Асинхронный Telegram-бот на Python с использованием библиотеки **aiogram 3** и **FSM (Конечного автомата состояний)** для пошагового сбора данных от клиентов и отправки оформленной заявки администратору.

---

## ✨ Возможности и сценарий работы

1. **Приветствие**: бот приветствует пользователя при вводе команды `/start` и предлагает начать оформление заявки.
2. **Пошаговый сбор данных (FSM)**:
   - 👤 **Имя** (текстовый ввод)
   - 📱 **Номер телефона** (ввод вручную или кнопка «Поделиться контактом»)
   - 🏙️ **Город съёмки** (текстовый ввод)
   - 📸 **Формат съёмки** (быстрый выбор по кнопкам или свой вариант текстом)
3. **Промежуточное подтверждение каждого шага**:
   - После каждого шага бот выводит введённые пользователем данные и inline-кнопки:
     - `✅ Всё верно` — переход к следующему вопросу.
     - `✏️ Изменить` — возможность повторно ввести данные текущего шага.
4. **Финальное подтверждение**:
   - После ответа на все вопросы бот формирует итоговую карточку заявки с кнопками:
     - `✅ Отправить заявку`
     - `🔄 Заполнить заново`
     - `❌ Отменить`
5. **Отправка администратору**:
   - После подтверждения заявка мгновенно пересылается администраторам в Telegram с подробной информацией (имя, телефон, город, формат съемки, ссылка на профиль, username, Telegram ID и время создания).
   - Пользователь получает уведомление об успешной отправке.

## 🚀 Быстрый запуск

### 1. Клонирование / открытие проекта
Убедитесь, что у вас установлен **Python 3.10+** (проверено на Python 3.11 - 3.14).

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Откройте или создайте файл `.env` в корне проекта:
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrSTUvwxYZ
ADMIN_IDS=123456789,987654321
```

> 💡 **Где взять значения:**
> - **BOT_TOKEN**: создайте бота в Telegram через [@BotFather](https://t.me/BotFather) и скопируйте выданный API токен.
> - **ADMIN_IDS**: ваш числовой ID Telegram (можно узнать в [@userinfobot](https://t.me/userinfobot) или [@ShowJsonBot](https://t.me/ShowJsonBot)). Если администраторов несколько, укажите их через запятую.
> - **Важно**: администратор должен хотя бы один раз нажать `/start` в боте, чтобы бот имел право присылать ему сообщения.

### 4. Запуск бота
```bash
python main.py
```

## 🛠️ Команды бота

- `/start` — Главное меню и приветствие
- `/apply` — Начать заполнение заявки на съёмку
- `/cancel` — Отменить текущее заполнение заявки на любом шаге
- `/help` — Справка по использованию бота
